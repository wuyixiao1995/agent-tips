# AI Agent 实用技巧集

收集在使用 AI Agent（WorkBuddy / Claude Code / OpenClaw 等）过程中沉淀下来的**实用技巧与 Skill**。每个技巧一个文件夹：`README.md` 是通俗讲解（给想了解思路的人读），`SKILL.md` 是可直接装进任意 agent 的原始技能文件（给想直接用的人拿走）。

## 目录

| # | 技巧 | 一句话简介 |
|---|------|-----------|
| 01 | [长任务接力（会话连续性）](./01-长任务接力-会话连续性/) | 长 session 会「变蠢」、跨 session 会「失忆」？用「收尾/继续」协议把长任务切成一段段干净的对话，进度不丢、状态可接力 |

## 设计理念

这些技巧大多是**介质无关**的：逻辑层讲的是架构和协议，换任何 agent 平台都成立；只有介质层（文件路径、阈值）需要按平台适配。欢迎 fork / 提 issue 交流。
